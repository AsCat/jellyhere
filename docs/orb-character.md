# 果冻悬浮角色与授权码

当前 Android 开发版提供三款程序绘制的矢量角色，无外部图片素材，缩放后保持清晰：

| 角色 | 视觉 | 含义 |
| --- | --- | --- |
| 圆圆 | 天蓝色圆脸、红晕、呼吸和眨眼 | 默认伙伴 |
| 芽芽 | 绿色种子形身体、两片大叶 | 轻快与成长 |
| 星星 | 暖黄色五角星身体、琥珀色描边 | 探索与测试 |

在果冻主界面点选角色后，悬浮球立即换装。角色右下角的状态点表示连接状态：绿色已连接、橙色连接中、灰色暂停。角色拖到任一侧松手后立即滑入边缘，只露出约 27dp；单击即可打开靠边的紧凑菜单。菜单优先显示状态和暂停/恢复，关闭后角色会重新贴边；长按不再直接修改无线调试设置。

托管模式的菜单提供“打开控制台”，使用当前绑定服务器的 HTTPS 地址在手机浏览器打开网页管理界面；需在浏览器登录自己的设备空间。自托管模式保留“打开果冻”入口，不把维护者实例地址写入开源 App。

点菜单中的“无线调试”，会在本机运行开发测试快捷流程。它识别桌面搜索、无线调试结果及系统开关，读回地址后才报告成功；遇到不认识的界面会停下并打开开发者设置供手动完成。成功匹配的元素 ID 和次数留在本机，不上传操作录像。小米已完成真机验证；三星的电脑端 `jellyhere adb connect` 恢复链路已验证，手机本地悬浮球路径仍需单独验收。详见[快捷操作与多设备](shortcuts.md)。

自托管模式的临时 HTTPS 授权码已移入果冻主界面的“临时 HTTPS 授权与高级操作”；托管模式隐藏这组入口，在网页管理智能体授权。控制码要求先填写已安装的可调试 App 包名。口令由本机点击生成，展示 60 秒倒计时，配对成功后立即清除。无法连接或暂停时不会生成口令。主界面或悬浮菜单的“更多选项”可撤销当前临时授权。

远程读屏、点击、滑动和输入时，角色会探出，并在角色前方的同一位置叠加小道具：读屏滚动页、点击手指、按真实方向移动的滑动手指，以及小键盘和打字手指。只读取界面树也会触发读屏动画；工作反馈按自身帧时钟播放，不依赖系统开发者选项的动画时长设置。角色本体仍由 `OrbFaceView` 绘制；道具由独立、不可触摸的 `OrbEffectView` 绘制，因此换用圆圆、芽芽或星星时共用同一套动作。角色只做轻微配合动作，道具连续绘制动画，不切换图片帧。完成后短暂显示勾号。

说话状态同样绘制在 `OrbEffectView`，占据角色右上方，可与工作道具同时显示。语音模块完成后可在 `OrbAccessibilityService` 调用 `onSpeechPlaybackChanged(true)` 开始、`onSpeechPlaybackChanged(false)` 结束；目前没有接入语音播放事件。语音结束只关闭说话道具，不打断正在执行的工作动作。

紧凑的小字气泡跟着角色，优先显示在角色上方、沿同一侧屏幕边缘；靠近顶部时移到角色下方。它只显示动作类型与完成状态，不显示屏幕文字或输入内容；可在气泡中直接暂停远程访问，通知栏也提供暂停入口。暂停立即拒绝后续请求，已经交给系统的手势可能需等待结束。动画只在手机本地悬浮层显示，不进入远程截图。

远程截图或手势执行时会暂时隐藏整个悬浮层，包括气泡和菜单；完成后恢复并短暂显示结果。现有 MCP 令牌独立于临时 HTTPS 授权。此界面仅用于开发测试，不提供支付或下单授权。
