# JellyHere v0.5.5 · 首个公开预览版

果冻让智能体通过 MCP 查看 Android 手机屏幕与界面元素，并在用户明确授权后执行开发测试操作。手机主动连接 Go relay；电脑和手机无需处于同一局域网，日常运行也不依赖无线 ADB。

## 下载

- `jellyhere-android-0.5.5.apk`：Android 11+，使用维护者固定签名。
- `jellyhere-server_linux_amd64`、`jellyhere-server_linux_arm64`：自托管 Go relay。
- `checksums.sha256`：以上三个文件的 SHA-256 校验值。

Android APK 与当前 JellyHub 站点提供的 0.5.5 文件逐字节相同。三星 SM-F936U 已安装该正式签名文件；小米 2304FPN6DC 当前安装的是同版本的调试签名包。Linux amd64 服务端已在独立本机端口通过健康检查；arm64 包完成交叉编译，尚未在 arm64 主机上验收。

## 主要能力

- 跨网络读屏、压缩截图、无障碍界面树，以及点击、滑动、输入等受控操作。
- JellyHub 可扫码绑定多台 Android 设备，并按设备授予智能体只读或控制权限；手机悬浮角色可暂停远程访问。
- `jellyhere` CLI 可查看设备状态，并在可达的同一网络内辅助恢复无线 ADB。
- WorkBuddy 的 JellyHere 连接器已通过平台审核并发布；在浏览器中选择设备和权限完成 OAuth 授权。

## 开始使用

托管试用：打开 [JellyHub](https://jellyhub.yuanxuyinli.com/)，使用 GitHub 登录、安装 APK、扫码绑定手机，再在 WorkBuddy 市场连接 JellyHere。自托管：按[快速开始](https://github.com/AsCat/jellyhere/blob/v0.5.5/docs/quickstart.md)配置自己的 Go relay 和 MCP 客户端。

首次使用需在 Android 设置中手动启用无障碍服务。调试签名与正式签名不同；从调试包切换到本 APK 时，先备份连接信息，再卸载调试包并重新配置。屏幕锁定认证仍由手机系统和用户完成。付款与最终下单不属于普通远程控制授权。

完整变更见 [CHANGELOG](https://github.com/AsCat/jellyhere/blob/v0.5.5/CHANGELOG.md)。本版为预览版，欢迎通过仓库 Issue 反馈机型、系统版本和复现步骤。
