# JellyHere v0.5.6 · 统一果冻图标

这版把用户选定的暖黄色“星星果冻”和清爽蓝 `#3B6FAB` 用作 Android 启动图标、网站页头与 favicon。Android 通知栏使用对应的单色星形图标。新安装用户默认看到星星悬浮角色；已有角色选择保持不变。

## 下载

- `jellyhere-android-0.5.6.apk`：Android 11+，延续 v0.5.5 的固定发布签名，`versionCode=22`。
- `jellyhere-server_linux_amd64`、`jellyhere-server_linux_arm64`：自托管 Go relay。
- `checksums.sha256`：以上三个资产的 SHA-256 校验值。

Android 启动图标通过 adaptive icon 适配系统形状。调试签名包无法由正式签名 APK 直接覆盖；从调试版切换前请备份连接信息，卸载后再配置。三星正式签名包可直接覆盖上一版；小米目前安装调试签名包，因此使用对应调试构建验收。

WorkBuddy 连接器的同款图标已放入 **0.1.2 更新候选包**。连接器市场上的图标须待该更新重新审核并发布后才会变化；Android 与网站的更新不会自动改动市场图标。

安装与自托管方式见[快速开始](https://github.com/AsCat/jellyhere/blob/v0.5.6/docs/quickstart.md)，矢量母版与生成方式见[品牌图标说明](https://github.com/AsCat/jellyhere/blob/v0.5.6/docs/brand-assets.md)。
