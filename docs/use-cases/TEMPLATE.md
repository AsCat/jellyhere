# 场景 NN：标题

> 日期 · 智能体 · 设备 · 目标 App

## 用户目标

> 用户的原始指令，隐去个人信息。

## 实测结果

用一两句话说明最终停在哪个界面、完成了哪些步骤，以及哪些动作没有执行。若记录耗时，注明它只是本次运行结果。

## 关键过程

1. 智能体如何确定目标设备和当前界面。
2. 通过果冻执行了哪些有代表性的操作。
3. 如何核对结果、处理异常或交还用户。

## 截图
